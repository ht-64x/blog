三毛机场 + Clash：一年三块钱的梯子怎么用

发表于2026-10-17|更新于2026-10-17|数码玩机技巧
|浏览量:

先说结论

我在用的这个叫三毛机场，最便宜的套餐 ¥3/年（每月 5G 流量）。延迟实测还行，日常刷网页、看文档够用。

这篇记录一下它是怎么回事，以及怎么用 Clash 导入订阅。

说明：本文只是个人使用记录，不构成推荐。这类服务稳定性参差不齐、随时可能跑路，请自己判断。请遵守当地法律法规，不要用于任何违法用途。

什么是”机场”

“机场”是圈内对代理订阅服务商的俗称。你自己搭一个代理服务器当然也行，但要买 VPS、配协议、还要防封，折腾成本不低。

机场的思路是把这些打包卖给你：

好处是省事，坏处是你把流量交给了第三方，而且服务商说关就关。

一个值得注意的地方

它的计价方式有点反直觉：年付的流量天花板比月付低很多。

  • 年付最贵的一档（¥29.9/年）只有 500G/月
  • 月付 ¥8 那档有 3000G/月

按”每 G 流量单价”算，反而是超大流量套餐最划算（约 0.0027 元/G）。所以：

  • 轻度用户（只看网页、查资料）：¥3 或 ¥12.99 的年付就够，一年花个位数，这就是”三毛”这个外号的由来
  • 重度用户（看视频、下大文件）：别去年付，直接月付大流量更合适

我选的是年付那档，因为我主要用它查文档和看技术资料，一个月几个 G 都用不完。

Clash 是什么

Clash 是一个代理客户端，不是一个机场。这两件事经常被搞混：

作用
机场提供节点（服务器）
Clash决定哪些流量走节点、哪些直连

Clash 最实用的能力是规则分流。你可以让它：

  • 访问 GitHub、Google → 走节点
  • 访问 B 站、淘宝、微信 → 直接连，不浪费流量
  • 访问公司内网 → 直连

配置好之后你基本不用管它，开着就行。

Clash 本体（原版）已经停止维护，现在常见的是各种衍生客户端，比如 Windows 上的 Clash Verge / Mihomo Party、macOS 上的 ClashX / Clash Verge、Android 上的 Clash for Android / FlClash。操作逻辑基本一致。

完整步骤

第一步：买套餐

在官网注册、选套餐、付款。付完之后进入用户中心，能看到自己的订阅信息。

第二步：拿订阅地址

这一步是关键。在用户中心找到「一键订阅」之类的入口，点开会有几个选项：

菜单里有这么几项：

  • 扫描二维码订阅 —— 手机端用，Clash 里扫码导入
  • 复制订阅地址 —— 得到那个 URL，手动粘贴
  • 导入到 Clash —— 有的机场做了 clash:// 协议唤起，点一下直接调起本机 Clash

推荐用「复制订阅地址」，最通用，不依赖系统是否关联了 clash://。

⚠️ 这个 URL 就是你的账号凭证，不要发给别人，也不要贴到公开的地方。泄露了别人就能白嫖你的流量，甚至影响你账号。

第三步：导入 Clash

以桌面端为例，大致是这样：

  1. 打开 Clash 客户端，切到配置（Profiles）页
  2. 点「新建配置」/「导入」/ 输入框
  3. 把刚才复制的订阅地址粘贴进去，确认
  4. 客户端会去下载配置，成功后列表里会多出一个配置文件
  5. 点一下把它设为当前使用（有的客户端叫”启用”）

手机端更简单：在 Clash for Android / FlClash 里找到「配置 → 新建 → 从 URL 导入」，粘贴地址即可；或者直接用「扫描二维码订阅」。

第四步：选节点

配置导入后，进代理（Proxies）页面，能看到一串节点，名字可能是「香港 01」「日本 02」这种。

  • 手动挑一个延迟低的（客户端一般会显示延迟数字，点一下可以测速）
  • 或者选「自动选择 / URL-Test」这类策略组，让它自己挑最快的

第五步：刷新

草稿里我写的是”刷新一下就可以了”——这一步不能省。

因为：

  • 机场会不定期换节点（旧 IP 被封了就换新的）
  • 你本地的配置是上次拉取的快照，节点可能已经失效

所以感觉”突然连不上了”的时候，第一件事就是去 Clash 里点「更新订阅」，而不是怀疑自己配置错了。

常见问题

导入时报错 / 拉取失败？

先确认订阅地址完整（有的机场地址很长，容易漏字符）。如果地址没问题，可能是机场服务器在维护，过一会儿再试。

能连上但没网？

检查两件事：① 系统代理是否真的开了（Clash 里有个”系统代理”开关）② 规则模式是不是把你要访问的网站判给了”直连”。切到「全局模式」试一下，如果全局能用，说明是规则问题。

网速慢？

换个节点试试，优先挑延迟低的。晚高峰（20:00-24:00）普遍会慢，这个没办法。

手机上怎么用？

Android 用 Clash for Android 或 FlClash，导入方式和桌面端一样。iOS 上 Clash 系客户端基本都下架了，需要在非国区 App Store 另想办法。

几点提醒

1. 别把重要的东西放在这类服务上

机场能看到你的流量走向（虽然 HTTPS 内容本身是加密的）。用它查资料、看视频没问题，但别用它登录重要账号、做敏感操作。

2. 便宜就意味着不稳定

¥3 一年的服务，你不能指望它有商业级 SLA。随时可能挂、可能跑路，所以别一次充好几年。按年付最多也就亏三十块，心态放平。

3. 记得更新订阅

这是最容易忘的一步，也是”突然用不了”最常见的原因。

4. 合规使用

这类工具本身是中性技术，但请遵守当地法律法规，不要用于任何违法用途。你是成年人，自己判断。

我的使用感受

用了几天，记录一下：

优点

  • 便宜到几乎没有决策成本，一年三块钱
  • 延迟确实”还可以”，查 GitHub、看文档、刷技术博客都够用
  • 订阅导入流程标准，Clash 的规则分流配好之后基本不用管

不足

  • 节点质量不稳定，晚高峰会明显变慢
  • 流量套餐的定价逻辑有点怪（年付流量上限低）
  • 这类小机场没有售后保障，出问题大概率只能等

适合谁：偶尔需要查海外资料、预算极低、不介意折腾的人。
不适合谁：需要稳定长连接（比如远程办公、大文件传输）的人 —— 那还是老实买正规服务。
