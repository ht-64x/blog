magpie：一个网关，管住我所有 Agent 的模型

发表于2026-11-15|更新于2026-11-15|数码玩机技巧
|浏览量:

先说我原来的状态，可能跟你一样。

我电脑上同时装了 codex、claude code、gemini cli，还有 dsh。每个工具都把自己的模型写在自己的配置文件里，格式还都不一样：codex 认 OpenAI 那套 Responses，claude code 只认 Anthropic 的 Messages，gemini 又是另一种。你想给某个工具换个模型，就得去翻它的配置文件，改 base_url，改模型名，改完还不敢确定改对了没有，只能跑一句「你好，你是谁」试探一下。

更烦的是额度。我在 workbuddy 薅了一堆免费 token，在 deepseek 充了点钱，claude 那边还有个订阅，但这些额度是散的，claude 的订阅只能在 claude code 里用，你想拿它喂 codex，没法直接喂。

那有没有一个东西，能让这些 agent 都从同一个地方取模型。

有的兄弟有的，这个东西就是 magpie。

它到底干了什么

说穿了很简单，它在你自己电脑上跑一个小服务，默认大概在 127.0.0.1 的某个端口，然后把你所有 agent 的请求都指过来。

关键在于它会翻译。codex 发过来的是 OpenAI Responses 格式的请求，magpie 在中间把它翻成你要接的那家厂商认识的样子，反过来再把结果翻回来。流式输出、工具调用、推理过程这些都得跟着翻，翻漏了工具就跑不起来，这也是这类网关最难的地方。

所以你在 magpie 里配一次模型，codex、claude code、gemini cli、opencode、pi 这些全都能用。你改一次，全跟着变。不用再一个个去翻配置文件了。

它甚至能读你 agent 的登录信息，你 claude code 和 codex 里已经登着的订阅，它直接认出来，不用你再抄一遍 key。不想要这个行为的话设置里能关掉，我一开始也犹豫了一下，毕竟让它读登录信息听着有点过，但它本来就是本地跑的东西，也就不纠结了。

我用下来最有用的三件事

第一是分组。它能把一堆模型打包成一个虚拟名字，比如 group/xxx，agent 那边只看到一个名字，实际背后是一组模型在轮换。你想让便宜的模型先上，贵的兜底，或者几家的 key 排队用，就在组里排好就行。

第二是自动换号。这个真的救命，尤其是白嫖来的额度。某个账号被限流了返回 429，它自己就切下一个，你这边完全没感觉。以前遇到这种情况我只能干等，或者手动去配置文件里换 key，现在不用管。

第三是账本。它会把每个 agent 用了多少、走的哪个模型、花了多少 token 记下来。我第一次看到的时候有点意外，原来我大部分请求都是些没营养的短对话，真正难的那几条才用得上贵模型，看到这个之后我才知道该怎么配。

装起来麻烦吗

不麻烦，比配那些 agent 本身简单多了。

装完之后是一句命令加一个 key 的事，比如接 deepseek 就是给个 sk- 开头的 key，接 ollama 那种本地跑的连 key 都不用。它有界面，菜单栏或者托盘里，不是纯命令行，这点对我不太爱背命令的人挺友好。

支持的家数挺多的，国产那几家基本都在，openrouter 也在，本地的 ollama 也行。官方说有二十多家供应商、几十个编程工具，我也没数过，反正我常用的都在里面。

几个我自己踩过的

一是别把它当成套壳的中转站。它是本地跑的网关，请求从你电脑出去，直连你要的那家厂商，中间没有第三个服务器。这点我特意确认过，因为我不想让 prompt 再多过一手。

二是模型名要对着填。有次我把 claude 的模型名填成了 deepseek 的，它不报错，就是一直返回很奇怪的东西，我排查了半天才发现是名字对不上。这种错误不提示，你自己注意。

三是免费额度的坑还是那些。网关帮你自动换号，但换到没号可换的时候该报错还是报错，而且有些平台的条款是禁止多号绕限流的，你自己权衡，我只能说别把重要的东西挂在上面。

值不值

如果你只用一个大模型、只用一个 agent，那你不需要它，纯增加一层。

但只要你满足下面任意一条，它就挺值：装了不止一个 agent；手上有几家的额度想混着用；想按任务难易自动分派模型省钱；或者单纯受够了每次换模型去改三个不同格式的配置文件。

我属于全中，所以它现在是我电脑上开机自启的少数几个东西之一。

最后提一句，它是开源的，代码在 yetone/magpie，本地的东西，免费。具体怎么配官方文档写得比我清楚，我就不照抄一遍了。

碎碎念一下吧。我以前一直觉得「换个模型」是件小事，改个配置的事。后来发现不是，麻烦的从来不是改那一下，是你不知道改了之后哪里会坏。网关这种东西的意义不在于省那几分钟，它把「模型」从一个绑死在某个工具里的东西，变成了一个可以随便换的部件。这个感觉挺重要的，就像以前显卡驱动、打印机驱动那种破事，后来被系统统一收编了，你才不用管它。

现在模型选择这块，正在经历同一件事。
