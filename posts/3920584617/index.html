magpie：把各种免费渠道的 AI 聚起来用

发表于2026-11-15|更新于2026-11-15|数码玩机技巧
|浏览量:

先说一个我很长时间没解决的事。

我手上散着一堆 AI 额度：workbuddy 送的免费 token、deepseek 充的几十块、claude 那边还有个订阅、偶尔注册个新平台又给点体验金。听起来挺富裕对吧，但实际上我根本用不起来。因为这些额度是绑死的——workbuddy 的积分只能在 workbuddy 里花，claude 的订阅只能在 claude code 里用，你想拿它喂给 dsh，没法喂，格式不对，接口不对，你只能眼巴巴看着一堆额度过期。

那有没有办法把这些渠道全接进来，让我在任何一个工具里都能随便挑着用。

有的兄弟有的，这个东西就是 magpie。

它是干什么的

一句话：它是一个跑在你自己电脑上的 AI 管理软件，专门用来聚合各种免费渠道——你把手上的 key、订阅、免费额度都接进去，它就给你一个统一的入口，你所有的 agent 都从这个入口拿模型。

它的核心本事是翻译协议。codex 只认 OpenAI 那套 Responses 格式，claude code 只认 Anthropic 的 Messages 格式，gemini 又是另一套，而各家模型厂商的接口又各不相同。magpie 夹在中间，把请求翻成目标厂商认识的样子，再把结果翻回来——流式输出、工具调用、推理过程这些都得跟着翻，翻漏一个工具就废了，这也是这类软件最难的地方。

所以效果是：你在它那里配一次，codex、claude code、gemini cli、opencode、dsh 全都能用，改一次全跟着变。不用再一个个去翻配置文件改 base_url 了。

它具体能帮你干成什么事

这才是我觉得值得写一篇的原因，光说”统一管理”太虚了，说几个真的能省钱的。

把免费额度榨干。这是我最看重的一点。多数免费渠道都有限流，用着用着就 429。magpie 可以配多账号、多渠道，一条路被限流了它自己切下一条，你这边完全没感觉。以前我遇到限流只能干等，或者手动去改配置换 key，现在它自己扛着，我该干嘛干嘛。你手上那些零零碎碎的体验金，终于能一起用起来了。

一个模型名字背后放一组。它能把多个渠道打包成一个虚拟的组，agent 那边只看到一个名字，实际背后是一组模型在轮换。你可以让免费的排前面，快用完的顶上来，实在不行再动贵的。这个组合方式自己定，等于给自己做了个调度。

复用你已经在付的钱。它会去读你 agent 的登录信息，你 claude code 和 codex 里本来就登着的订阅，它直接认出来，不用你再抄一遍 key。于是那份 claude 订阅就不只能给 claude code 用了，codex 也能用上，dsh 也能用上。这个对已经花了钱的人来说是实打实回本。（不想让它读登录信息可以在设置里关掉，我犹豫过，但它本地跑的东西，我就没纠结。）

按活儿的难易分派。有了统一入口，你就能做以前做不了的事：简单活走免费模型，难的交贵的。它有个账本，会记每个 agent 用了多少、走的哪个模型、花了多少 token。我第一次看的时候有点意外——原来我大部分请求都是些没营养的短对话，真正难的就那几条。看到这个我才知道钱该往哪花。

还有一点容易忽略的。以前你想试某个新模型，得先去装那个模型对应的工具，折腾半天才发现不好用，白装。现在只要你把渠道接进 magpie，手头任何一个 agent 都能立刻试试，不行就换回来，试错成本几乎为零。

用起来麻烦吗

不麻烦，比配那些 agent 本身简单多了。

装完是加渠道 + 把 agent 指过来两步。加渠道基本就是给个 key，比如 deepseek 填个 sk- 开头的，接 ollama 那种本地跑的连 key 都不用。它有界面，在菜单栏或者托盘里，不是纯命令行。

支持的家数挺多，国产那几家基本都在，openrouter 也在，本地 ollama 也行。官方说有二十多家供应商、几十个编程工具，我常用的都在里面，没细数。

几个注意的

它是本地跑的。请求从你电脑直连你要的厂商，中间没有第三个服务器。这点我特意确认过，因为我不想让 prompt 再多过一手。所以它跟你平时用那些第三方中转站不是一回事。

模型名要对着填。有次我把 claude 的模型名填成了 deepseek 的，它不报错，就是一直返回很奇怪的东西，我排查半天才发现是名字对不上。这种错不提示，自己注意。

免费额度该有的限制还在。它帮你自动换号，但换到没号可换的时候该报错还是报错；而且有些平台的条款是禁止多号绕限流的，你自己权衡。我的态度是：拿它跑不重要的活、能容忍中断的活，别把要紧的东西挂上去。

只用一个大模型、一个 agent 的人不需要它。那是纯增加一层。但只要你装了不止一个 agent、或者手上有几家的额度想混着用，它的价值立刻就出来了。

最后

它是开源的，代码在 yetone/magpie，本地的，免费。怎么配官方文档写得比我清楚，我不照抄。

说句实在的，这东西让我对”额度”这件事的看法变了。以前我觉得免费额度就是鸡肋，零散、限流、绑在特定工具上，聊胜于无。现在它们能被聚到一个池子里，按我的需要流到任何地方去。

对我这种没什么钱、又想多用几个模型的人来说，这个意义比”统一配置”大得多——它把那些本来会白白过期的免费额度，变成了真的能干活的东西。
